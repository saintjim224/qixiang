# 融天气象：界面与交互验收记录

本记录对应本轮本地开发检查；资源版本 `20261003_4`。它是软件验收记录，不是来源标签审计、标准符合性认定或真实业务成效证明。

## 本轮修复

| 问题 | 修复与验证 |
|---|---|
| 切县后出现新县标题与旧县指标 | 下拉框显式传入目标县域，由加载函数统一切换；旧值立即清空，晚到响应不能覆盖新县。浏览器检查色尼区与巴宜区切换 |
| 微网格结论颠倒、提示缺少名称 | 按行比较季节、按列比较草场；保留名称与季节元数据。色尼区季节间最大极差 30，草场间最大极差 6 |
| 历史拟合被写成独立预测 | NPP 图单列历史参考值、历史拟合及 2026 年情景预测；年度单位更正为 kgC/m²/年 |
| 气候背景曲线冒出“实时预报”标记 | 完全降级时整条曲线使用虚线，不再出现实时分界或实时来源提示 |
| 验证计算超时、部分成功遮盖另一项失败 | PU/NPP 各自加载、错误与重试，计算等待上限 60 秒；并发调用共用同一请求 |
| 外部预报空温度造成服务错误 | 验证完整逐日数据；空值/非有限值/缺县响应显式降级，0℃ 保留，风速显式请求 m/s |
| 应急页重复科研说明 | 移除重复成绩板块，保留业务测算与登记；降级数据标明仅用于情景推演 |

## 自动化结果

- `python -m pytest -q`：31 passed，21.96 秒。3 个警告来自 SHAP 对绘图库待弃用接口的调用。
- `node --test tests/frontend_state.test.js tests/frontend_charts.test.js`：9 passed。覆盖请求合并、独立错误状态、县域重载与迟到响应、矩阵语义、降级曲线来源、年度 NPP 与拟合/预测分离。
- 前端 JavaScript 语法检查通过；`git diff --check` 通过。

## 浏览器场景

- 桌面 1440×1000、手机 390×844 下，五个导航页面均检查。布局记录中可用内容宽度分别为 1425 与 375 像素（右侧滚动条占宽）；页面总滚动宽度与其相同，没有整页横向溢出。
- 色尼区：五页加载完成后，无可见错误状态块。NPP 年度图、数据覆盖图和地图实际渲染。
- 巴宜区：SPI 为 -1.28，GDI 为 0.1524；PU 无可用历史样本，显示不可评估，不填入其他县域分数。
- 模拟登记：填写干草 10 吨、精料 2 吨，保存后显示预算 1.57 万元、状态“模拟登记”。通过 `MR_DISPATCH_LOG` 写入独立测试文件，原始两条样例文件哈希未改变。
- 测试完成后恢复默认视口，运行服务恢复使用原始样例日志。原始样例与本地模拟均非正式业务调度。
