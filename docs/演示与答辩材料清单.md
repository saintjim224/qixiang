### 2.2 必讲的三处"诚实披露"（有评分价值，不要删）

1. **SPI 的定位边界**：ERA5 仅 6 年，每县同月可用样本 2–6 个，远低于 WMO 建议的 ≥30 年。第三方 `spei` 独立实现交叉校验得 26 县 ×2 尺度的分档一致率中位约 30%，故 SPI 在本系统中定位为**同口径相对趋势与等级重判**，不作为绝对气候统计量引用。依据可核验：`tools/cross_validate_spi.py` 与 `tools/out/spi_cross_check.json`。
2. **PU 验证边界**：当前为 2024 年留出诊断，训练只使用 2020–2023 年。旧版 F1 0.5769 已弃用；本轮标签 F1 0.1856 也不能解释为真实灾害识别效果，因为验证集没有经核验的真实阴性标签。具体结果以 `tools/out/pu_temporal_evaluation.json` 为准。
3. **1,373 条未标注样本的性质**：既非负样本也非"无灾害"，是统计盲区。严禁在任何材料中表述为负类。

### 2.3 建议补充的两张自制图

- **零构建前端模块架构图**：14 个 IIFE 模块按依赖顺序串成一条链
  `core/namespace → tokens → format → api → provenance → charts/theme → charts/manager → ui/states → ui/method → ui/router → state/store → charts/*Charts → app.js`，
  标注"无打包器、无 ES Module、双击 `index.html` 即可运行（模块脚本在 `file://` 下会因 CORS 全白屏，这是刻意规避的失败模式）"。
- **数据链三阶段拓扑图**：原始观测 → 模型派生 → 下游应用模拟，与五级可信度徽章一一对应。

## 三、截图 / 无头校验命令（可复用）

WSL 下用 Windows Chrome 无头模式截图。**每次必须换一个全局唯一的 `--user-data-dir`**，否则 Chrome 会直接返回上一轮的缓存页面，得到与改动前逐字节相同的假结果。

```bash
# 截某页整屏（示例：Tab3 风险指数，色尼区 + 抽屉展开）
TS=$(date +%s%N)
MSYS_NO_PATHCONV=1 "/mnt/c/Program Files/Google/Chrome/Application/chrome.exe" \
  --headless=new --disable-gpu --no-sandbox --disk-cache-size=1 \
  --virtual-time-budget=45000 --window-size=1600,2600 \
  --user-data-dir="C:\tmp\mrcap_${TS}" \
  --screenshot="C:\tmp\s3_index.png" \
  "http://127.0.0.1:8001/#/index?region=naqu-seni&drawer=spi"

# 取渲染后的 DOM 做断言（页签是否正确、有无 error 状态块、画布数）
MSYS_NO_PATHCONV=1 "/mnt/c/Program Files/Google/Chrome/Application/chrome.exe" \
  --headless=new --disable-gpu --no-sandbox --disk-cache-size=1 \
  --virtual-time-budget=30000 --window-size=1600,1400 \
  --user-data-dir="C:\tmp\mrdump_${TS}" \
  --dump-dom "http://127.0.0.1:8001/" > /tmp/page.html
grep -o 'status-block' /tmp/page.html | wc -l   # 期望 0（处于 ok 态）
grep -o '<canvas' /tmp/page.html | wc -l        # Tab1 期望 3
```
