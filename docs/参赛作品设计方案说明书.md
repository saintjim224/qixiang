## 一、 作品概述

### 1.1 项目背景
青藏高原被誉为“世界屋脊”与“亚洲水塔”，是国家生态安全的重要屏障和典型的高寒畜牧业经济区。然而，该区域平均海拔在 4,000 米以上，气候极端脆弱，冬季暴雪（白灾）、严寒冷冻、春季干旱（黑灾）频发，对高寒牧区的牲畜生存繁衍、草场生态健康以及牧民生计构成了长期且严重的系统性威胁。

2024 年至 2026 年，随着全球气候变化加剧，极端水热波动的频次与烈度显著提升，传统气象灾害监测“重宏观预报、轻微观承灾体、缺生态草畜机理映射”的断层愈发凸显。如何在广袤无垠、地形复杂的青藏高原上，将多源卫星遥感反演、地表气象驱动与生态机理模型深度融合，构建高精度、可解释、低误报的气象灾害风险智能预警系统，成为气象科学赋能高原特色农业现代化的重大科学与工程命题。

### 1.2 目标定位
本项目面向高原牧区的气象风险分析、草畜平衡与应急方案推演，组合公开数据、模型计算与可追溯来源展示。目前为研究演示原型，事件标签、跨区域泛化和业务参数仍需核验，尚未对接正式调度或金融审批系统。

系统定位于：
1. **干旱指数计算**：使用 Gamma 分布与零降水概率计算 SPI，同时披露当前仅有 6 年历史数据的统计局限；
2. **草地退化指标对照**：使用 PCA 载荷加权、草场系数及聚类分档构建研究性 GDI，并展示与旧等权方法的差异；论文对应关系及生态准确性仍需独立核验；
3. **未标注样本学习**：现有 127 条带来源标签与 1,373 条未标注县月记录，尝试 PU Learning 并披露时间留出结果。来源记录仍含非气象事件，不能直接称为核验灾情真值；
4. **NPP 验证与边界展示**：使用 26 县、2001–2025 年的 650 条年度参考值进行 LOYO 留年验证及 LORO 留县验证，比较 MAE、RMSE 和 R²。LOYO 不等于严格未来预测，LORO 结果尚不足以支持跨县业务应用；
5. **应急方案推演**：按设定的存栏规模、补饲参数及价格测算草料需求、预算与资金参考值，保存本地模拟记录；尚未开展正式调度、授信或理赔。

以上各项的适用边界集中于 §6.2 统一说明，正文不再逐条复述。

## 二、 需求分析与核心痛点

### 2.1 政策与标准依据

本作品的服务对象与指标口径均锚定现行政策与国家标准（**正式提交前需按最新版本逐条复核文号与条款**）：

1. **《气象高质量发展纲要（2022—2035 年）》**：明确要求提升气象服务精细化水平与灾害风险预警能力，为本作品“从宏观预报走向县域承灾体”的技术路线提供依据；
2. **《中华人民共和国青藏高原生态保护法》**：将青藏高原生态安全屏障保护上升为法律要求，支撑本作品以草地退化与草畜平衡为核心指标的选择；
3. **中央一号文件与政策性农业保险相关部署**：连续要求强化农业气象灾害监测预警、发展农业保险与农村数字普惠金融，对应本作品“保险 + 信贷”的风控链路；
4. **GB/T 20482 牧区雪灾等级国家标准**：作为雪灾分级判定的阈值依据（**版本年份须复核，见 §6.2**）；
5. **GB/T 20481-2017 气象干旱等级**：作为 SPI 干旱分级的判定依据。

### 2.2 需求调研过程与依据

本作品的需求来源为**公开资料调研 + 数据实证**两条路径，不使用需单位背书的访谈口径：

1. **公开灾情记录的结构化梳理**：将 2020–2024 年带来源链接的 127 条已标注事件按类别分布统计（接口 `/api/datasource/verified-events`），据此识别牧区最集中的灾害类型与记录特征；
2. **经营主体样本核查**：随包收录 76 条牧区经营主体记录（`app/data/data_store/business_subjects.json`），含存栏规模与信贷额度字段，用于确定承灾体计量单位（牲畜头数）与资金口径；
3. **自然地理与气候背景分析**：对 4 省区 26 个重点牧区县域的海拔、草场类型与降水序列做分布分析，确认“干旱季零降水”与“秋末枯黄期”两类典型样本特征；
4. **需求归纳**：由以上三条路径导出三大痛点（§2.3–§2.5），并反向确定所需的数据类型（逐日气象 + 年度遥感）与算法特性（抗零降水、抗季节性、抗标签污染）。

> **边界**：以上为公开资料与随包数据的研究性分析，**不构成实地调研或业务需求确认**；真实需求须由后续试点验证。

### 2.3 痛点一：传统气象指数在高原极端气候下的“数学失真”
高原冬季气候极度干旱少雨，许多高寒荒漠县域（如阿里改则县）在 12 月连续多年降水观测值为 0。传统通用气象指数模型往往直接计算 Z-score 均值方差，造成极小分母下的方差塌陷，导致在无降水月份频繁爆出“-3.5 以下特大干旱”虚警，严重消耗政府与牧民的应急防灾信任。因此，必须引入带有零降水概率混合累积分布的标准 Gamma 拟合。

### 2.4 痛点二：退化监测算法粗暴导致的“全域同级”
部分现有评估系统采用简单的指标等权归一化算法评估草地退化。由于高寒草场具有明显的季节性落叶休眠特征，一到秋末枯黄期，所有县域各项绿度指标均降至低谷，导致 26 个县全部落入“中度退化”或“重度退化”，失去了空间选址与差异化调度的参考价值。必须复现论文级 PCA 主成分降维与草甸/草原/荒漠物理脆弱性空间系数。

### 2.5 痛点三：真实灾情样本的“未标注负类污染”
气象防灾与保险领域的实际业务痛点在于：灾情通报是有记录成本的，官方见诸报道的往往是因灾伤亡达到重大阈值的事件（真实正例，Positive）。而没有报道记录的历史月份，既包含完全风调雨顺的月份，也包含受灾较轻但未上报的月份（未标注，Unlabeled）。
将未标注样本全部视为无灾会引入潜在标签偏差，但当前数据没有核验的真实阴性，无法据此确定错误标签比例或真实误报率。本项目用 PU Learning 探索这一问题，并将记录标签诊断与真实灾害效果区分展示。

## 三、 气象数据底座与四大核心 AI 算法

本系统坚持“数据有源、公式有据、代码开源、实测可验”的设计准则，构建了坚实的多源气象时空底座，并落地四大核心算法模块。

### 3.1 多源时空数据底座规约

```
[TPDC CMFD 混合版本子集 (2015-2024)] ──┐
[ECMWF ERA5 (随包 2020-2025)]      ├──> [多源长时序气象驱动空间] ──┐
[Open-Meteo 实时与预报]       ──┘                               │
                                                                 ├──> [多尺度气象灾害决策大脑]
[NASA MOD17A3HGF (2001-2025)] ──┐                               │
[NASA MCD12Q2 (2003-2024)]    ├──> [遥感生态与物候特征空间] ──┘
[官方灾情通报凭证 (127条)]     ──┘
```

- **数据事实边界分级**：
  1. **公开数据产品**：TPDC CMFD 逐月混合版本子集（2015–2024）、ERA5 逐日再分析子集（2020–2025）、MOD17A3HGF 25 年 NPP 遥感产品；不统一称为地面实测；
  2. **带来源的事件标签**：127 条已标注记录；来源链接本身不能证明县域归属、金额单位或气象关联正确；
  3. **未标注背景样本**：1,373 条历史月度时空特征，严禁混淆为负样本；
  4. **派生推导标注**：所有由公式、PCA 或模型衍生的指数均带 `is_derived=True` 标识。

### 3.2 模块一：标准 SPI 气象干旱 Gamma 拟合算法 (`app/algorithm/spi.py`)
针对标准化降水指数（SPI），严格实现世界气象组织（WMO）推荐的标准算法：
1. **Gamma 分布建模**：利用极大似然法（MLE）拟合非零降水量的形状参数 $\alpha$ 与尺度参数 $\beta$：
   $$g(x) = \frac{1}{\beta^\alpha \Gamma(\alpha)} x^{\alpha - 1} e^{-x / \beta} \quad (x > 0)$$
2. **零降水概率边界 $q$ 修正**：设历史 $N$ 年中降水量为 0 的年数为 $m$，则 $q = m / N$。混合累积分布为：
   $$H(x) = q + (1 - q) G(x)$$
3. **正态逆变换**：通过标准正态逆分布函数转换获得标准分位数：$SPI = \Phi^{-1}(H(x))$。
4. **口径一致性与样本量边界**：自动提取历史相同日历月份的滑动窗口（3/6/12个月），消除跨季节方差偏折；同时客观披露，受限于高原可用序列长度（实测 $N=4\sim 5$ 年，起始年份 2020），标准 SPI 与简化 Z-score 在 26 县全域的平均绝对偏差为 **0.0985**（最大单县偏差 0.55），差异主要源于标准分级口径规整与零降水边界修正。

> **气象数据的具体作用**：以 CMFD / ERA5 逐日降水序列为唯一输入，按日历月滑动窗口聚合为 3 / 6 / 12 个月累积降水量，直接决定干湿分位的位置。
> **AI 技术的选用依据与融合关系**：高原冬季月降水大量为 0，通用 Z-score 的正态假设不成立，故选用 Gamma 极大似然拟合并以零降水概率 $q$ 构造混合累积分布；该统计模型是后续干旱分级与灾害判定的基础算子。

### 3.3 模块二：论文级草地退化指数 GDI 复现 (`app/algorithm/gdi.py`)
严格复现 *Li et al. (2025, Remote Sensing)* 论文流程：
1. **多维特征空间构建**：整合 NPP、NDVI、植被覆盖度 (FVC) 与折算干草产量；
2. **主成分降维**：经实测，第一主成分（PC1）解释方差比为 **59.55%**，前两主成分累计解释方差比达 **98.36%**，具有极高的统计代表性；
3. **草场脆弱性修正**：高寒草甸（系数 0.70）、高寒草原（系数 1.00）、高寒荒漠（系数 1.35）；
4. **曲率分级与聚类**：依据综合退化特征曲线的拐点（0.1589, 0.5032, 0.7502），自然划分为：基本稳定（15.4%）、轻度退化（42.3%）、中度退化（30.8%）、重度退化（11.5%），彻底消除了“全域同级”的平庸结果。

> **气象数据的具体作用**：遥感生态量（NPP、NDVI、FVC）的年内节律由温度与降水的季节驱动决定，气象序列用于解释秋末枯黄期全区域绿度同步塌陷的成因，避免将其误读为退化加剧。
> **AI 技术的选用依据与融合关系**：等权 Min-Max 归一化无法区分“季节性绿度下降”与“结构性退化”，故选用 PCA 主成分降维（PC1 解释 59.55%）叠加草甸/草原/荒漠物理脆弱性系数，再由 K-Means 配合曲率拐点确定分级阈值。

### 3.4 模块三：正例-未标注学习 (PU Learning) 灾害评估 (`app/algorithm/pu_model.py`)
针对现有已标注记录（$P$）与未标注样本（$U$），构建两步集成学习方案：
1. **候选负例筛选**：基于 XGBoost Bagging 的袋外（OOB）评分筛选候选 RN；没有袋外预测的样本不得作为低风险样本。评测时先划分训练/验证，再仅用训练期筛 RN；具体数量随划分与参数变化，以复现报告为准；
2. **代理标签校准**：在 $P \cup RN$ 上使用 `CalibratedClassifierCV(method='sigmoid')`。由于 RN 并非核验阴性，输出称为模型风险评分，不宣称具有真实致灾概率含义；
3. **SHAP 解释**：展示基础分类器的特征贡献与历史样本月份。它反映模型统计关联，不构成因果解释，也不代表当前灾情。

> **气象数据的具体作用**：16 维输入特征中有 7 维为同期气象要素（气温窗口均值、降水累积、积雪深度、连续积雪日数、SPI 干旱值等），它们是雪灾与干旱风险的直接驱动因子，其余为地理与季节上下文特征。
> **AI 技术的选用依据与融合关系**：灾情记录只有正例、无核验阴性，朴素监督学习会把未标注月份当负例从而系统性低估风险，故选用 Bagging 袋外评分筛选可靠负例，再以 Platt 校准输出概率，并用 SHAP 提供逐样本归因。

### 3.5 模块四：草地 NPP 时空预测与双向验证协议 (`app/algorithm/yield_forecast.py`)
使用随包 26 县 × 25 年（2001–2025 年）的 650 条 NPP 年度产品参考值，设置两类分组验证：
1. **协议 A: 留一年交叉验证 (LOYO)**：每轮以 1 年（26 县）为测试集，其余 24 年为训练集，共 25 轮。训练集可能包含测试年之后的数据，且使用同期气象特征，因此不能据此证明事前未来预测能力；
2. **协议 B: 留一县交叉验证 (LORO)**：26 轮外推，每轮以 1 县（25 年序列）为测试集，其余 25 县为训练集，检验模型在未知县域的零样本空间泛化能力；
3. **经典基线对标**：严格与“历史气候态均值 (Climatological Mean)”、“线性趋势外推 (Linear Trend OLS)”与“近3年移动平均 (3-Year MA)”进行横向对标，输出 MAE、RMSE、$R^2$ 及误差相对降低率。

> **气象数据的具体作用**：生长季气温均值、SPI 干旱指数与积雪要素作为回归特征参与建模，是 NPP 年际波动的气象解释变量；遥感 NPP 本身作为预测目标而非输入，避免信息泄漏。
> **AI 技术的选用依据与融合关系**：LOYO 留年协议下选用 L2 正则化 Ridge 以抑制 26 县基数差异带来的过拟合；LORO 留县协议下改用环境梯度非线性回归，以应对“训练集中不含目标县任何年份”的零样本外推场景。两类协议回答不同问题，不可互相替代。

## 六、 总结、局限性与未来展望

### 6.1 项目总结
本项目把县域气象风险、草地指标、历史模型解释与应急方案推演组织为一个可运行工作台。目前已有可复现的算法对照与模拟业务链路；主要不足在于来源标签质量、标准核验、严格时间预测和跨县验证。作品价值应由可演示的任务流程、可追溯的数据及明确的适用边界支持，不以“首创”或实际减灾成效作未经验证的承诺。

### 6.2 科学事实与局限性声明（诚实边界）
作为负责任的科研参赛作品，本方案诚实披露当前系统的客观边界：
1. **SPI 样本规模与方差波动**：青藏高原各县月度可用历史同月降水序列实测为 4~5 年（起始年份统一为 2020）。虽严谨按照 WMO 推荐两参数 Gamma MLE 拟合、零降水概率 $q$ 及正态逆累积变换，但受限于样本量 $N$，参数估计方差客观存在；实测全域 26 县标准 SPI 与旧版简化 Z-score 平均绝对偏差为 **0.0985**（最大单县偏差 0.55），等级判定差异主要源于标准分级口径规整与零降水边界修正（全域扫描、默认尺度 scale=3 下仅日喀则市谢通门县 2025-01 触发 $q=0.20$，即 5 年中该月有 1 年零降水；尺度降至 scale=1 时阿里改则 2025-12 亦触发同样的 $q=0.20$，属尺度差异）；
2. **NPP 时空预测指标客观机制**：
   - **LOYO 留年验证**采用平方损失与 L2 正则化的 Ridge。当前 MAE 较气候态基线低，但 RMSE (0.0249) 高于该基线 (0.0202)。这些是本次评测结果，不能推导为 L1/中位数拟合，也不能未经误差审计就归因于雪灾年份；
   - **LOYO 各模型呈现的 $R^2 \approx 0.956\sim0.998$ 统计数值**，主因 26 县海拔地理跨度巨大（3000~4800m），县际年均基数方差远高于年际细微波动（$\sim 0.01$），保留县均值即可在统计上获得高 $R^2$；三条基线中仅“近 3 年移动平均”明显偏低（0.9561），其预测受前 3 年单点波动牵引，在极端年份附近反而放大了年际噪声；
   - **LORO 空间跨区盲测中**，在缺乏局地微尺度土壤水热实测数据时，向全新县域空间外推极其严苛（各方案 $R^2$ 均为负值），但本系统通过环境梯度非线性回归将跨区未知空间外推 MAE 降低约 20%；
3. **样本规模与适用范围**：随包数据为 26 县、25 年、650 条参考值；尚未建立独立地面生产力核验集。LOYO 与 LORO 回答不同问题，不能仅比较两者数值就作整体泛化结论；
4. **微气象站点密度**：青藏高原部分极高海拔垭口缺乏实体气象自动站，短期预报仍依赖 Open-Meteo 与 ERA5 格点再分析，高程垂直修正目前基于 0.0065 ℃/m 经验减温率；
5. **商务与资金口径均为情景设定**：存栏规模、活体单价、补饲率、损失率、授信放大系数等均为可调整的情景参数（随响应体 `assumptions` 字段披露），并非真实经营数据。§5.3 的成本节省、损失敞口与授信额度均属**情景测算**，不构成已实现的业务成效；
6. **引用标准的版本与适用性待核**：雪灾判级引用 GB/T 20482，干旱分级引用 GB/T 20481-2017；当前实现采用的是简化阈值，**尚未逐条对照现行标准全文**，故正文引用处均标注“待复核”，正式提交前须完成条款—代码对应表；
7. **价值量化指标受预报源档位支配**：§5.3 第 2–5 项由本次预报窗口驱动。实时预报接口不可达时系统回退到气候态外推序列，同口径下干草需求由 358.4 吨升至 964.0 吨、损失敞口由 225.25 万元升至 2,048.5 万元（2.7 倍 / 9.1 倍）。这是**降级策略的必然结果而非算法错误**，系统以 `realtime_counties` 字段如实披露档位；任何引用该组数值的材料都必须同时写明档位，不得只取两个档位中较有利的一侧。
